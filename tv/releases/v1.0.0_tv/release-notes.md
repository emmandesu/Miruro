# Miruro TV 1.0.0_tv

## First Android TV edition
- Separate TV app with landscape layout, launcher banner and clear remote focus.
- Native navigation rail for Home, Discover, Search, History, Downloads and Client Settings.
- D-pad navigation across site cards, menus, episode lists and text fields.
- OK plays/pauses on the player; Left/Right seeks 10 seconds; Up opens playback tools.
- Native playback bar with captions, settings, fullscreen and download access.
- Fullscreen keeps the existing video. Back closes controls and returns to browsing.
- TV keyboard support, first-use remote guide and browser Back/forward restoration.
- Existing custom DNS, popup protection, sign-in windows, diagnostics and download queue.
- Independent TV update channel; installs alongside the phone version.

Requires Android TV/Google TV with Android 9+ and an up-to-date Android System WebView. Downloads need a compatible TV file picker/storage provider. Physical Xiaomi TV/remote and live service testing remain pending.
