# Miruro 1.0.40

## Client Settings navigation

- Added **Back to menu** when Client Settings was opened from Miruro's site menu.
- Added labeled Back actions on settings pages, including nested screens like release notes and live logs. Returning to Client Settings keeps your search and scroll position.
- Android Back returns to the previous menu. The **×** still closes settings.
