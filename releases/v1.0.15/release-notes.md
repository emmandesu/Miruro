Miruro 1.0.15 connects in-app updates to emmandesu/Miruro on GitHub.

- Client Settings → General → App updates checks this repository's published metadata.
- Daily and manual checks, download progress, cancellation and retry.
- SHA-256, package, version and signing-certificate checks before installation.
- Android confirmation for installation, plus a reminder after leaving the watch page.
- Update downloads use your selected DNS provider; no GitHub token is embedded in the app.

Install this version manually once to switch from the earlier reserved update address. Subsequent newer releases can use in-app updates.
