# Miruro 1.0.35

## Connection
- AdGuard is now the default DNS provider. Open Client Settings → Connection to choose AdGuard, Cloudflare (1.1.1.1), or System DNS.
- NextDNS has been removed. If you used it, the update switches you to AdGuard. Existing AdGuard and System DNS selections stay as they are.
- Browsing, stream preparation, new downloads and app updates use your selection. Changing providers reloads the current page; active downloads keep their original provider.
